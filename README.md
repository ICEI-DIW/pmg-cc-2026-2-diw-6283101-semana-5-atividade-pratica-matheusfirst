### Base do Projeto

Para esse projeto, escolhi desenvolver um web site que possui como núcleo de conteúdo a entidade primária de coleção (Criptídeos) e a entidade secundária (categorias de criptídeos), ou seja, o núcleo "coleções e itens".

### Objetivo do Projeto

Esse projeto tem o intuito de ser um ambiente descentralizado, no qual a própria comunidade que se interessa pelo assunto de criptídeos e pseudociência digital constrói e mantém o acervo do ***Cryptid Catalogue***, além de participar de melhorias, de blogs e de jogos relacionados ao assunto na própria web page.  

### Tecnologias Implementadas

Neste projeto, foram utilizadas as tecnologias front-end HTML e CSS para a criação da interface *Web* do ***Cryptide Catalogue***. No HTML, para a estruturação principal, foram utilizadas as tags que melhor trazem significado para o *Browser* durante a renderização da página — `<header></header>`, `<nav></nav>`, `<main></main>`, `<section></section>` e `<footer></footer>`. No CSS, foram utilizadas propriedades focadas em responsividade e dinamismo que vão além do dispositivo utilizado para acessar *Cryptide Catalogue*. Por sua vez, aplicou-se media queries para alterar o layout de acordo com a tela do usuário, layout Flex e Grid para criação de alinhamento, de cards e de seções para as informações desenvolvidas ao longo da página.
